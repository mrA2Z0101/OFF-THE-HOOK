Drop files here

PDFs, Word, Excel and PowerPoint files, ZIP archives, web pages, pictures with QR codes. Up to 100 MB each.

Checking an email attachment

  1. Download it, but don't open it. Downloading is safe; opening is when a bad file does damage.
  2. Drag it here from your Downloads folder (or the browser's download list), or click Choose files.
  3. Dangerous? Delete it, and report the email to IT. Be careful? Only open it if you expected it, and never click "Enable content".

What it looks for

  • Files pretending to be something else: a "PDF" that is really a program, a web page or a shortcut
  • PDFs that run code, start programs, carry hidden files, or exist only to send you to a website (those links get the same checks as email links)
  • Office files with macros, "Enable content" tricks, DDE commands, or content pulled from the internet when opened
  • Password-protected or nested archives, and risky files inside archives
  • Web page attachments with fake sign-in forms, redirects or scrambled code
  • QR codes in pictures and inside PDFs, and where they really go

No checker catches everything, and a clean result doesn't prove a file is safe. If you weren't expecting a file, ask the sender through a channel you already trust.
